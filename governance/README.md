# Governance Directory

This directory contains governance-related artifacts, proposals, runbooks, and tooling.

## Structure

- **`payloads/`** - Reusable proposal payload builders
- **`proposals/`** - JSON proposal artifacts (for staging and execution)
- **`runbooks/`** - Operational runbooks for common governance tasks
- **`checks/`** - Post-execution verification scripts

## Usage

See individual subdirectories for documentation on their contents.
