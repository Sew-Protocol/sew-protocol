# Governance Docs

This folder contains the protocol governance architecture, process runbook, constraints, and surface mapping.

## Start here
- `GOVERNANCE.md` - Protocol governance architecture (canonical reference: token, voting, timelock, lanes, roles, emergency path, power limits)
- `GOVERNANCE_CONSTRAINTS.md` - Enforced governance limits (what governance cannot do)
- `GOVERNANCE_PROCESS.md` - Governance process runbook (Forum -> Vote -> Timelock -> Execute)
- `GOVERNANCE_SURFACE_MAP.md` - Function-to-role/lane/delay mapping
- `IMPLEMENTATION_STATUS.md` - Governance implementation status (retained in place)
